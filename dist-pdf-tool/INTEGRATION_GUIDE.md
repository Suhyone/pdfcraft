# คู่มือการเชื่อมต่อระบบเว็บของบริษัท และแนวทางพัฒนาต่อยอด (PdfCraft Web Tool)

## 1. วิธีเรียกเปิดโปรแกรมเมื่อผู้ใช้กดเปิดไฟล์ PDF บนเว็บบริษัท

หลังจากอัปโหลดโฟลเดอร์ `dist-pdf-tool/` ไปไว้บนเซิร์ฟเวอร์ (เช่น `/pdf-tool/`) เว็บหลักของบริษัทสามารถเรียกเปิดไฟล์ PDF ได้ 2 รูปแบบ:

### รูปแบบที่ 1: เปิดเป็น ลิงก์ / แท็บใหม่ (ง่ายที่สุด)
เปลี่ยนลิงก์ดาวน์โหลด PDF เดิมของบริษัท ให้ชี้มาที่ `/pdf-tool/index.html` พร้อมส่ง URL พารามิเตอร์:
```html
<a href="/pdf-tool/index.html?load_url=get_pdf.php%3Fid%3D123&save_url=save_pdf.php%3Fid%3D123&name=สัญญาจ้าง.pdf&author=สมชาย" target="_blank">
  เปิด / แก้ไข PDF
</a>
```

### รูปแบบที่ 2: เปิดเป็น Full-screen Modal `<iframe>` ในหน้าเว็บเดิม (ดูตัวอย่างใน `company_demo.php`)
- ใช้ `<iframe src="/pdf-tool/index.html?load_url=...&name=...&author=...">`
- หน้าเว็บหลักสามารถดักฟัง `window.addEventListener("message", ...)` เพื่อรับแจ้งเตือนจาก `bridge.js`:
  - `company-pdf:ready` — โปรแกรมโหลดเสร็จพร้อมใช้งาน
  - `company-pdf:dirty` — ผู้ใช้มีการแก้ไขเอกสารที่ยังไม่ได้กดเซฟ (`event.data.dirty === true`)
  - `company-pdf:saved` — ผู้ใช้กด Save บันทึกกลับเข้าเซิร์ฟเวอร์เรียบร้อยแล้ว (`event.data.name`)

### พารามิเตอร์ URL ที่รองรับทั้งหมด
| พารามิเตอร์ | คำอธิบาย | ตัวอย่าง |
|---|---|---|
| `load_url` | URL ของไฟล์ PHP สำหรับดึงข้อมูล PDF (ต้องอยู่โดเมนเดียวกัน) | `get_pdf.php?id=123` |
| `save_url` | URL ของไฟล์ PHP สำหรับรับข้อมูล PDF ตอนกด Save (`POST`) | `save_pdf.php?id=123` |
| `name` | ชื่อไฟล์ที่แสดงบนแถบหัวเอกสาร (รองรับภาษาไทย UTF-8) | `เอกสารสัญญา_2026.pdf` |
| `author` | ชื่อพนักงานที่จะถูกนำไปใส่เป็นผู้เขียนคอมเมนต์/โน้ตอัตโนมัติ | `สมชาย ฝ่ายกฎหมาย` |
| `help` | ตั้งเป็น `0` หากต้องการซ่อนปุ่ม `? คู่มือใช้งาน` | `help=0` |
| `control` | เปิด API `window.pdfcraft` ให้หน้าเว็บสั่งงานผ่าน JavaScript (ดูหัวข้อ 3 ข้อ 4) | `control=1` |

## 2. การทำงานของคู่มือแนะนำการใช้งานครั้งแรก (First-Time Onboarding)
- เมื่อพนักงานเปิดใช้งานครั้งแรก `bridge.js` จะตรวจค่า `localStorage.getItem("pdfcraft_onboarding_v1")`
- หากยังไม่เคยเข้าใช้งาน จะแสดงหน้าต่างแนะนำ **5 เครื่องมือหลักที่ใช้บ่อย** (เลื่อน/ซูม/ค้นหา, ไฮไลต์/คอมเมนต์, พิมพ์ข้อความ/ลงลายเซ็น, หมุน/จัดการหน้า, และการกด `Ctrl+S` เพื่อบันทึกกลับเข้าระบบ)
- เมื่อติ๊ก `"ไม่ต้องแสดงหน้าต่างนี้อีกในครั้งถัดไป"` และกด `"เริ่มใช้งานเลย"` ระบบจะจำค่าไว้และไม่เด้งซ้ำอีก
- พนักงานสามารถกดปุ่ม **`? คู่มือใช้งาน`** ที่มุมขวาล่างเพื่อเปิดดูคู่มือซ้ำได้ตลอดเวลา

## 3. แนวทางพัฒนาต่อยอดในอนาคต (Future Development Roadmap)

1. **การเชื่อมระบบยืนยันตัวตนและสิทธิ์การใช้งาน (Authentication & Permission):**
   - เนื่องจาก `bridge.js` ส่งคำขอแบบ `credentials: "same-origin"` อยู่แล้ว จึงแนบ `PHPSESSID` / Cookie ของเว็บหลักไปที่ `get_pdf.php` และ `save_pdf.php` โดยอัตโนมัติ
   - สามารถเพิ่มโค้ด `session_start();` ใน `get_pdf.php` และ `save_pdf.php` เพื่อตรวจสิทธิ์ของพนักงานก่อนอนุญาตให้เปิดหรือบันทึกทับไฟล์ได้ทันที
2. **ระบบเก็บประวัติการแก้ไขและสำรองไฟล์อัตโนมัติ (Versioning & Audit Log):**
   - ใน `save_pdf.php` ก่อนเขียนทับไฟล์เดิม สามารถสำรองไฟล์เก่าเป็น `versions/{id}_{timestamp}_{user}.pdf` และบันทึกลงฐานข้อมูล MySQL ว่าใครเป็นผู้กดบันทึกเมื่อใด
3. **การปรับแต่งเครื่องมือเริ่มต้นให้เหมาะกับแผนก (Pre-configured Workspace):**
   - ตัวแอปเก็บค่าการตั้งค่า UI (เช่น โหมดมืด/สว่าง, แถบเครื่องมือที่ปักหมุดไว้) ใน `localStorage` คีย์ `"pdfcraft"`
   - สามารถให้ `bridge.js` ตั้งค่าเริ่มต้นใน `localStorage.getItem("pdfcraft")` เพื่อให้พนักงานใหม่เห็นเฉพาะปุ่มเครื่องมือที่แผนกต้องใช้ตั้งแต่เปิดครั้งแรกได้
4. **การสั่งงานอัตโนมัติจากหน้าเว็บด้วย `window.pdfcraft` API (`?control=1`):**
   - หากเพิ่ม `&control=1` ใน URL หน้าเว็บของบริษัทสามารถสั่งงานตัวโปรแกรมผ่าน JavaScript ได้โดยตรง เช่น:
     - `await iframe.contentWindow.pdfcraft.execute("file.save")` (สร้างปุ่ม "บันทึกเอกสาร" บนแถบเมนูของเว็บหลักเอง)
     - `await iframe.contentWindow.pdfcraft.docInspect()` (ตรวจสอบว่าเปิดอยู่หน้าไหน ซูมเท่าไหร่)
5. **การลดขนาดไฟล์ `.wasm` (51 MB -> ~6–12 MB) และการเปิดใช้งาน OCR ภาษาไทย/อังกฤษ:**
   - สามารถรัน `wasm-opt -Oz` หรือบีบอัดไฟล์ล่วงหน้าด้วย `gzip -k -9 *.wasm` คู่กับ `.htaccess` เพื่อให้โหลดผ่านอินเทอร์เน็ตเร็วขึ้น 5–8 เท่า
   - หากต้องการใช้ฟีเจอร์สแกนข้อความจากภาพ (Scan & OCR) บนเว็บ ให้รัน `cargo xtask models dist/web/models` แล้วอัปโหลดโฟลเดอร์ `models/` ไปวางคู่กับ `index.html`
